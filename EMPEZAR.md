# Cómo empezar

1. Crea una carpeta en tu ordenador llamada `web-abletonfacil`.
2. Descomprime este kit dentro. Tienen que quedar `CLAUDE.md`, `EMPEZAR.md`, la carpeta `fichas` y la carpeta `referencia`.
3. Abre Claude Code en esa carpeta.
4. Pega este primer mensaje:

```
Lee CLAUDE.md y abre referencia/prototipo.html. Quiero montar la web de abletonfacil tal y como está descrita ahí, con las 17 fichas de la carpeta fichas. Si me falta instalar algo en el ordenador, guíame paso a paso. Cuando la tengas, enséñamela funcionando en mi ordenador. Después la subimos a mi GitHub y la publicamos en Netlify.
```

5. Ve aceptando lo que te pida y pregúntale todo lo que no entiendas.

## Lo que tienes que tener a mano

- Tu usuario y contraseña de GitHub (los metes tú cuando te lo pida, nunca se los des en el chat).
- Una cuenta en Netlify. Puedes crearla con tu cuenta de GitHub.
- Los enlaces de tus productos de Ko-fi, cuando quieras cambiar los de ejemplo.

## Para añadir una ficha

Copia cualquier archivo de `fichas`, cambia los datos y guárdalo con otro nombre. O pídeselo a Claude Code: «Hazme una ficha con este reel: [enlace] y este guion: [guion]».
